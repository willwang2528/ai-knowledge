# 图片 1：跨领域知识地图

**主题：** 推荐系统与 RAG 中召回、检索、排序、重排概念对照

**图片数量：** 1

**图片目标：**

让读者一眼看到两条链路的共同抽象职责，并理解 RAG Reranker 与推荐系统重排并非简单同义。

**视觉结构：**

- 16:9 横版信息图。
- 左侧是推荐系统纵向漏斗。
- 右侧是 RAG 纵向漏斗。
- 中间用三条横向色带连接共同职责：
  1. 找候选
  2. 判优先级
  3. 整理最终结果
- 每向下一层，漏斗宽度明显缩小、单候选计算精度提高。

**必须元素：**

- 推荐系统链路：
  - 全量内容池
  - 多路召回 / Candidate Generation
  - 合并、去重、硬过滤
  - 粗排 / Pre-ranking
  - 精排 / Ranking
  - 重排 / Post-ranking
  - 最终展示列表
- RAG 链路：
  - 文档 / Chunk 索引
  - 查询改写
  - 初次检索 / Retriever
  - 融合、去重、权限过滤
  - Rerank
  - Context Packing
  - LLM 生成答案
- 醒目标注：
  - `RAG Retriever ≈ 推荐召回`
  - `RAG Reranker ≈ 推荐精排`
  - `RAG Context Packing ≈ 推荐列表级重排的部分职责`
- 图例说明 `≈ 表示工程职责相似，不表示算法完全相同`。

**文字内容：**

- 顶部标题：`召回、检索、粗排、精排、Rerank：不要按名字背，要按链路位置理解`
- 底部总结：
  - `前段：覆盖与效率`
  - `中段：精度与区分`
  - `后段：整体约束与可用性`

**风格：**

- 专业科技信息图，浅色背景。
- 推荐系统用蓝色，RAG 用紫色，共同职责用橙色。
- 中文字体清晰，避免装饰性插画。
- 信息密度高但留白充足，适合技术公众号。

# 图片 2：双链路系统架构图

**主题：** 推荐系统与 RAG 的完整数据流

**图片数量：** 1

**图片目标：**

展示每个阶段的输入、输出、规模缩减和最核心目标。

**视觉结构：**

- 超宽横版，分上下两条平行泳道。
- 上方泳道：推荐系统。
- 下方泳道：RAG。
- 每个模块采用圆角矩形，箭头上标注示意候选规模。
- 模块下方用一句短语说明最重点解决的问题。

**必须元素：**

推荐系统泳道：

```text
百万/亿级 Item
→ 多路召回
→ 数百/数千候选
→ 过滤与去重
→ 粗排
→ 精排
→ 重排
→ 几个/几十个展示结果
```

短语：

- 召回：`不漏`
- 粗排：`算得动`
- 精排：`判得准`
- 重排：`整页好`

RAG 泳道：

```text
百万级 Chunk
→ 查询改写
→ BM25 / Dense / Hybrid Retrieval
→ Fusion + 权限过滤
→ Cross-Encoder Rerank
→ Context Packing
→ LLM + 引用
```

短语：

- 改写：`更好搜`
- 检索：`证据入围`
- Rerank：`相关性排准`
- Packing：`证据互补且不浪费`
- 生成：`证据变答案`

侧边加入计算趋势：

```text
向右：
候选数量减少
单候选计算成本增加
判断精度提高
```

**文字内容：**

- 标题：`同一个漏斗，两种产品：推荐系统 vs RAG`
- 警示框：
  - `下游只能重排已有候选`
  - `上游漏掉的优质 Item 或证据，后面无法找回`

**风格：**

- 架构图风格，白底、深色文字。
- 模块色彩从浅到深体现计算成本上升。
- 清晰、工程化、无人物、无 3D 效果。

# 图片 3：技术发展路线

**主题：** 从关键词和协同过滤到多阶段检索、Rerank 与 Agentic Retrieval

**图片数量：** 1

**图片目标：**

说明技术演进不是简单替换旧方法，而是不断重新划分“效率—精度—整体目标”的边界。

**视觉结构：**

- 16:9 横向时间轴。
- 上半部分为推荐系统路线。
- 下半部分为搜索/RAG 路线。
- 中间用一条贯穿全图的主矛盾：
  - `大规模低成本覆盖 ↔ 小规模高成本精确判断`

**必须元素：**

推荐系统路线：

```text
协同过滤 / 规则
→ 2016 Candidate Generation + Ranking
→ Pre-ranking 独立成层
→ 粗排—精排—重排级联
→ 跨阶段协调与列表级多目标
```

搜索/RAG 路线：

```text
关键词检索 / BM25
→ 2020 DPR Dense Retrieval
→ 2020 RAG
→ Retrieve & Re-Rank
→ ColBERT Late Interaction
→ Hybrid / Multi-source Retrieval
→ Agentic Retrieval
```

关键节点旁标注：

- `双塔：可预计算，适合大规模初检`
- `Cross-Encoder：联合建模，适合候选重排`
- `Late Interaction：效率与交互精度折中`
- `Agentic Retrieval：规划、拆解、重试、验证`

**文字内容：**

- 标题：`多阶段检索与排序：边界随着模型能力和计算预算持续移动`
- 底部结论：
  - `术语不是固定算法`
  - `职责由输入规模、目标和成本共同定义`

**风格：**

- 学术路线图与产品信息图结合。
- 时间轴节点简洁、配少量线性图标。
- 使用蓝紫渐变，重点结论用橙色。
- 适合 2K 分辨率公众号配图，中文排版清晰。
