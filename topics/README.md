# Topics

本目录用于存放 AI 学习主题。

## 目录规则

- 一个子目录对应一个主题。
- 目录名使用简洁、稳定的英文 kebab-case，例如 `rag`、`agent-memory`、`gui-agent`。
- 每个主题的全部知识资产都保存在自己的目录内。
- 所有主题统一在 Git `main` 分支维护。
- 单次提交尽量只新增或更新一个主题目录。

## 主题目录结构

```text
topic-name/
├── README.md
├── research.md
├── engineering.md
├── concepts.md
├── discussion.md
├── references.md
├── article.md
└── image_prompt.md
```
